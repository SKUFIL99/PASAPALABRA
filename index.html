✏️ Administrar preguntas

El juego incluye 156 preguntas bíblicas (6 por letra). Las modificaciones se guardan en este navegador. Usa exportar/importar para llevarlas a otro dispositivo. Selecciona «Empieza por» o «Contiene» para cada pregunta. Importar JSON reemplaza todo el banco.

Copias de seguridad

La importación reemplaza el banco de preguntas actual y reinicia el historial de preguntas utilizadas. El historial se guarda en este navegador; en otro dispositivo empieza por separado.
